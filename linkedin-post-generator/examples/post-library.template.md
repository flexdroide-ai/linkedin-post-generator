# 05_LINKEDIN_POST_LIBRARY_TEMPLATE

Questo file è un template da compilare con esempi di post che rappresentano bene la voce desiderata.

## Come usarlo
Inserisci qui 6–10 esempi di post LinkedIn che ti piacciono davvero.
Possono essere:
- post tuoi già pubblicati
- bozze che hai scritto e che ti sembrano riuscite
- post che vuoi usare come riferimento stilistico

## Per ogni esempio aggiungi:
- **Titolo interno / etichetta**
- **Testo del post**
- **Perché funziona**
- **Che tono rappresenta** (più manageriale, più engaging, più netto, più sobrio, ecc.)
- **Cosa Claude dovrebbe imitare**
- **Cosa Claude non deve imitare anche se il post funziona**
